 👑 Two Queens — Business Website

 📌 Project Overview

Two Queens is a small business inspired by Guatemalan roots, offering specialty coffee, matcha drinks, energy drinks, and sweet treats.

I developed this website to establish an online presence for the business and provide customers with easy access to its menu, events, merchandise, and contact information.

This project allowed me to apply web development skills to a real-world business.

 🛠️ Technologies Used

- **HTML5:** Website structure and content
- **CSS3:** Visual design and styling
- **JavaScript:** Interactive functionality
- **Git & GitHub:** Version control and project management
- **GitHub Pages:** Website hosting and deployment

 ✨ Website Features

- Home page introducing the brand
- Menu displaying products
- Merchandise section
- Events page
- Contact page
- Navigation between website sections

 💡 Skills Demonstrated

- Front-end web development
- Website structure and organization
- Version control using GitHub
- Website deployment and maintenance
- Troubleshooting and problem-solving
- Developing a technology solution for a small business
